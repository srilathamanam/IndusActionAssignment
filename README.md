# IndusActionAssignment
**Prerequisites:**
Python (>= 3.9)

**Install Dependencies using following command**
pip install -r requirements.txt

**setup supabase url and supabase key in .env file**
SUPABASE_URL=https:""
SUPABASE_KEY=""

**run application using follwoing command**
uvicorn app.main:app --reload
