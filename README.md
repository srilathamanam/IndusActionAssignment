# IndusActionAssignment
#Prerequisites
Python (>= 3.9)

1. Install Dependencies using following command: 
pip install -r requirements.txt

2, Setup supabase url and supabase key in .env file: 
SUPABASE_URL=""
SUPABASE_KEY=""

3. Run application using follwoing command:
uvicorn app.main:app --reload
